# World's Real Estate Data

This project explores a large real-estate dataset to identify patterns in property prices, areas and other features. The workflow covers data analysis, preprocessing, machine learning and SQL.

---

## 🔄 Project Pipeline & Structure

### 🔹 1. Exploratory Data Analysis (EDA)

- Dataset overview and data types
- Price, area and room analysis
- Missing values and outlier detection
- Country-level analysis

### 🔹 2. Feature Engineering & Pre-Processing

- Handling invalid values
- Cleaning area features
- Creating `price_per_sqm`
- Preparing features for modelling

### 🔹 3. Machine Learning Model Training

- Train/test split
- Baseline model
- Regression modelling
- Model evaluation with MAE, RMSE and R²

### 🔹 4. SQL Analysis

- Filtering and sorting data
- Aggregations with `COUNT()` and `AVG()`
- Grouping with `GROUP BY`
- Filtering groups with `HAVING`

---

## ⚙️ Tech Stack & Tools

- **Language:** Python, SQL
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn
- **Environment:** Jupyter Notebook, Kaggle
- **Database:** SQLite
